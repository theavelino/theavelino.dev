# theavelino.dev — Portfólio

## 📖 Resumo
Este repositório contém o meu portfólio pessoal (site). Aqui você encontra projetos, informações profissionais e formas de contato.


## 🛠️ Principais funcionalidades
- Página inicial com resumo profissional
- Seção de projetos com links e descrições
- Blog/Artigos (opcional)
- Contato / links para redes sociais e GitHub

## 🧑‍💻 Tecnologias
- ReactJS
- TailwindCSS


## 🤝 Como contribuir
- Abra uma issue para reportar bugs ou sugerir melhorias.
- Para contribuições: crie uma branch, faça commits claros e envie um pull request.
- Siga o padrão de código do projeto e adicione documentação quando necessário.
